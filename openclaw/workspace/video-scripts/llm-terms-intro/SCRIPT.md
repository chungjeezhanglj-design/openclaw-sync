## 术语分类清单

### 🏗️ 架构基础
1. **LLM** - 大语言模型，next-token 预测器
2. **Token** - 文本分片单位，BPE 分词
3. **Transformer** - 编码器 - 解码器架构
4. **Self-Attention** - 自注意力机制，QKV 计算
5. **Positional Encoding** - 位置编码，注入顺序信息

### 📚 训练方法
6. **Pre-training** - 预训练，海量数据学习语言规律
7. **Fine-tuning** - 微调，特定任务优化
8. **Instruction Tuning** - 指令微调，学会遵循指令
9. **RLHF** - 人类反馈强化学习，对齐人类价值观
10. **LoRA** - 参数高效微调，低秩适配器

### ⚙️ 推理优化
11. **Context Window** - 上下文窗口，最大 token 数
12. **KV Cache** - 缓存历史 Key/Value，加速生成
13. **Temperature** - 温度参数，控制随机性
14. **Top-k / Top-p** - 采样策略，平衡质量与多样性
15. **Beam Search** - 束搜索，保留多候选序列
16. **Quantization** - 量化，降低精度减少显存

### 🧠 核心概念
17. **Hallucination** - 幻觉，生成错误但合理的内容
18. **Embedding** - 文本向量化，语义空间映射
19. **Vector Database** - 向量数据库，近似最近邻检索

### 🔧 应用技术
20. **RAG** - 检索增强生成，减少幻觉
21. **Prompt Engineering** - 提示词工程，优化输入
22. **Chain-of-Thought** - 思维链，逐步推理
23. **Agent** - 智能体，自主规划执行
24. **Multi-modal** - 多模态，处理图文音视频

### 🎯 模型优化
25. **Knowledge Distillation** - 知识蒸馏，大模型教小模型

### 🛠️ 开发工具与协议
26. **MCP** - Model Context Protocol，模型上下文协议，连接 AI 与外部数据的标准接口
27. **Skill** - AI 技能模块，封装特定能力（天气查询、代码执行、视频制作等）
28. **LSP** - Language Server Protocol，语言服务器协议，编辑器理解代码的基础设施
29. **Tool Use** - 工具使用能力，模型调用计算器、搜索、代码解释器等外部工具
30. **Function Calling** - 函数调用，Tool Use 的具体实现，输出结构化 JSON 执行函数

## 制作建议

### 视觉风格
- **主色调**: 深蓝 (#0A192F) + 科技蓝 (#64FFDA) + 白
- **字体**: 中文用思源黑体，英文用 JetBrains Mono
- **图标**: 线性图标，简洁现代

### 动画节奏
- **架构类**: 用分解动画展示内部结构（Transformer、Attention）
- **流程类**: 用箭头和流动动画展示数据流向（RAG、RLHF）
- **对比类**: 用分屏对比展示效果差异（温度、采样策略）

### 配音语速
- **正常语速**: 约 220 字/分钟
- **关键术语**: 稍作停顿，给观众消化时间
- **复杂概念**: 适当放慢，配合动画节奏

### 背景音乐
- **风格**: Ambient Electronic / Chillstep
- **音量**: -25dB 以下，不抢配音
- **节奏**: 与场景切换同步，增强节奏感

### 信息密度控制
- **每场景**: 1-2 个核心概念，避免信息过载
- **视觉层次**: 主标题→关键图→辅助说明，三层结构
- **回顾节点**: 每 6-8 个术语后短暂总结，帮助记忆（架构→训练→推理→工具 四大模块）
