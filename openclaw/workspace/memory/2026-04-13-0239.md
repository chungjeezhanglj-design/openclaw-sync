### 📋 核心更新总览

2026.4.11 版本对 WebChat 进行了重大升级，主要包含三个方面：

| 特性 | 说明 | 变更号 |

### 1️⃣ 结构化聊天气泡 🫧

**什么是聊天气泡？**
- 将助手的输出指令（`MEDIA:`、回复标签、语音）渲染为**结构化的视觉元素**
- 不再是纯文本，而是**独立的 UI 组件**

**支持的指令类型**：

| 指令 | 渲染效果 | 示例 |
|------|----------|------|
| `MEDIA:` | 媒体卡片（图片/音频/视频/文件） | `MEDIA: ~/.openclaw/output.png` |
| `[[reply_to_current]]` | 回复引用气泡 | 显示被回复的消息 |
| `[[audio_as_voice]]` | 语音消息样式 | 语音波形播放器 |

**渲染前（纯文本）**：
```
好的，这是生成的图片：

MEDIA: ~/.openclaw/output.png

请查看。
```

**渲染后（结构化气泡）**：
```
┌─────────────────────────────┐
│ 好的，这是生成的图片：       │
│                             │
│ ┌─────────────────────────┐ │
│ │   [图片预览]            │ │
│ │   output.png            │ │
│ │   📎 下载                │ │
│ └─────────────────────────┘ │
│                             │
│ 请查看。                     │
└─────────────────────────────┘
```

---

### 2️⃣ `[embed ...]` 富内容嵌入标签 🔗

**什么是 embed 标签？**
- 用于在聊天气泡内**嵌入富 HTML 内容**
- 类似 iframe，但更安全、更轻量
- 仅支持**托管内容**（`/__openclaw__/canvas/...`）

**标签语法**：

```html
<!-- 自关闭形式（推荐） -->
[embed ref="cv_123" title="状态面板" height="320" /]

<!-- 或使用完整 URL -->
[embed url="/__openclaw__/canvas/documents/cv_123/index.html" 
       title="状态面板" 
       height="320" /]
```

**支持的属性**：

| 属性 | 说明 | 必填 |
|------|------|------|
| `ref` | 托管文档引用 ID | 二选一 |
| `url` | 完整托管 URL | 二选一 |
| `title` | 嵌入内容标题 | 否 |
| `height` | 高度（像素） | 否，默认 320 |
| `width` | 宽度（像素或百分比） | 否 |

**使用场景**：

| 场景 | 示例 |
|------|------|
| **状态面板** | 嵌入实时数据看板 |
| **交互式表单** | 嵌入配置表单 |
| **图表可视化** | 嵌入数据图表 |
| **文档预览** | 嵌入 Feishu/Notion 文档 |

**安全限制**：
- ❌ 不允许外部 URL（如 `https://example.com`）
- ✅ 仅允许 `/__openclaw__/canvas/...` 路径
- 🔒 可通过配置进一步限制：`gateway.controlUi.allowedOrigins`

---

### 3️⃣ TTS 音频持久化 🎵

**更新内容**：
- 助手生成的 **TTS 音频回复**现在会**保存到聊天历史**
- 音频与工具卡片**正确配对**，不会分离

**工作流程**：
```
用户请求 → 生成文字 → TTS 转语音 → 播放
                              ↓
              ┌───────────────┴───────────────┐
              │  保存到聊天历史（永久可用）    │
              └───────────────────────────────┘
```

**配置方式**：
```json5
{
  "talk": {
    "provider": "mlx-speech",
    "providers": {
      "mlx-speech": {
        "voice": "default",
        "persistHistory": true  // 保存到历史
      }
    }
  }
}
```

**效果对比**：

| 版本 | 音频历史 |
|------|----------|
| **2026.4.10 及之前** | ❌ 播放后丢失 |
| **2026.4.11+** | ✅ 永久保存，可重放 |

---

### 4️⃣ 配置外部嵌入 URL 🔐

**默认行为**：
- ❌ 禁止所有外部嵌入 URL
- ✅ 仅允许 `/__openclaw__/canvas/...` 路径

**如何允许特定外部 URL？**

```json5
{
  "gateway": {
    "controlUi": {
      "allowedOrigins": [
        "http://localhost:18789",
        "http://127.0.0.1:18789",
        "https://trusted.example.com"  // 添加信任域名
      ],
      "embedAllowlist": [
        "https://docs.openclaw.ai",
        "https://feishu.cn/docs/*"
      ]
    }
  }
}
```

**安全最佳实践**：
1. 优先使用托管内容（`ref="..."`）
2. 仅添加必要的信任域名
3. 避免使用通配符（`*`）
4. 定期审查允许列表
