### 项目要点（已沉淀到 MEMORY.md）

- **核心定位**：「Multilingual, non-autoregressive System 1 decision engine. Typed decisions over 100+ languages in a single forward pass — 33 ms」
- **Kahneman System 1 思维**（快、直觉、非生成）+ **RLCD**（strictly proper scoring rules）训练
- **3 个 checkpoint + Router**：
  - `laya` — ModernBERT-large / 421M / 512 ctx / 英语
  - `laya-multilingual` — mmBERT-base / 322M / 1024 ctx / 100+ 语种 / 2x 快
  - `laya-typed-decisions` — ModernBERT-large / 421M / 1024 ctx / typed-decisions workflow
- **类型系统**：`choice` / `score` / `noul`（nullable）
- **输入**：text / email / ticket / JSON document
- **输出**：typed decisions（**不生成文本**——不解析、不幻觉）
- **性能**：33 ms 单 forward pass（T4），7.2 ms/question batched
- **100+ 语种**
- **Apache-2.0 + PyPI + HF + GitHub 四位一体**
