### 项目实质

### 诊断算法（engine.js，看懂了）
- 每点最多 2 题。第 1 题对 → 该点 + **所有祖先**记「掌握（推断）」，不再问
- 第 1 题错 → 同点出第 2 题；第 2 题也错 → 「薄弱」，把未判定的直接先修（hard 先 soft 后）压栈顶**深度优先回溯**
- 第 2 题对 → 「不稳」(shaky)，**不回溯先修**（明确的设计取舍，README 局限里写了）
- 出题用 mulberry32 PRNG，种子由 `(seed, topicId, attempt)` 决定 → 同种子同作答出题完全一致，可 replay
- 学习路径 = 从根因 + 不稳点出发、沿被依赖方向可达、去掉已掌握，按年级从低到高排

### 数据完整性复核（23:02-23:10，异步 fetch 收尾）
- 用 GitHub **trees API**（`api.github.com/repos/<owner>/<repo>/git/trees/main?recursive=1`，102KB）取上游 main 全树 **316 个 blob 的 sha**，与本地 clone `/private/tmp/cmx`（HEAD `ddea0bfd`）逐项比对：**316/316 一致，0 差异** → 本地副本与上游 main 字节级相同，之前所有实测结论对上游成立
