## 关键信息（img2threejs）
- **11,784 ⭐ · 921 forks · 1 个月**（7/15 创建，速率夸张；最近 push 2 天前）
- **Apache-2.0**；赞助 Atlas Cloud
- **Pipeline 7 阶段 + 严格 quality gate**：blockout → structural → form → material → surface → lighting → interaction → optimization
- **核心创新** = "模型即代码"——输出 TypeScript `THREE.Group` factory + JSON spec，不是 mesh / glTF 二进制
- **token-efficient 6 条**：
  ① Python 脚本做机械活（验证/gating/spec 起草/PBR 提取/比较图打包），模型 token 只花在视觉判断
  ② **零依赖**——纯 Python 3.10+ stdlib，连 PIL/numpy/Playwright 都不用，PNG 用 `struct+zlib` 手解
  ③ pass-gated generation（每步只解锁当前阶段代码）
  ④ strict-quality gate 在写代码前 fail-fast
  ⑤ 每次评审只看一张 side-by-side 对比图
  ⑥ 输出是文本不是二进制，可 diff 可 review
- **多 track**：物体（hard-surface）+ 角色（anatomy-aware）+ hybrid
- **detailInventory**：先枚举身份特征 → 映射到组件/材质条目 → 不达标禁生成
- **多视图雕刻**（visualHull）：≥2 张正交轮廓求交生成 bounded voxel mesh
- **CS2 武器专属 review gates**
- **Live demos（10 个，全工业硬表面）**：Glock-18 Ghost Protocol / Classic Knife Fade / BMX Endurance / M9 Bayonet Doppler / Sony WF-1000XM3 / ISSACA 12-Gauge Shotgun / Gerber Paracord Knife / Doraemon House / War-Hauler / Crowned Loot Chest
- **Agent-agnostic**：Claude Code / Codex / OpenCode
- **安装**：skill 模式，单 checkout + 跨 host symlink（`~/.claude/skills/... -> <checkout>` + `~/.codex/skills/... -> <checkout>`）——跟 JJ-skill 同思路
- **生态**：showcase 仓（85⭐ TS）+ 社区 fork（nano-step / kxnakr-glock / TonyPythoneer）
