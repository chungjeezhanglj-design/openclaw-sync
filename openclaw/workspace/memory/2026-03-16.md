# 2026-03-16 离线地图道路样式调试

## 问题
道路图层没有显示，原因是：
1. 默认地图中心 (104.11, 33.96) 是山区，z14 无瓦片数据
2. streets 图层只在 z14 有数据
3. 需要正确配置道路样式（按等级分层渲染）

## 解决方案
1. 改到北京等大城市：(116.4, 39.9)
2. 缩放至 z14 查看道路
3. 按道路等级从低到高分层渲染（service → residential → tertiary → secondary → primary → trunk → motorway）

## 图层顺序
道路图层必须按等级从低到高渲染，高级别道路在上面：
1. service (灰色 #bdc3c7)
2. residential (浅灰 #95a5a6)
3. tertiary (青色 #1abc9c)
4. secondary (黄色 #f1c40f)
5. primary (橙色 #f39c12)
6. trunk (深橙 #e67e22)
7. motorway (红色 #e74c3c)
8. rail (蓝色虚线 #3498db)
