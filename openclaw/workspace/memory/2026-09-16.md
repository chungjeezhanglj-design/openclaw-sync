**关键技术发现**:

3. **URL Scheme**: `xdaoebike://`
4. **推测的 JL frame 布局**: `0xAA | len_lo | len_hi | cmd | seq | payload... | xor_checksum | 0x55`
5. **推测命令码**: 0x00 PING, 0x01 UNLOCK, 0x02 LOCK, 0x03 STATUS, 0x04 FIND, 0x05 ARM, 0x06 DISARM, 0x10 RECORDS, 0xF0 AUTH
6. **车 BLE 名字 pattern**: xdao / xd-ble / xdaoebike / smartbike / 小刀
7. **`control_*.json` 文件**是 **Lottie 动画**，**不是控制指令**（误导性命名）

**用户判断（关键）**: **「开锁不是蓝牙协议」** → 走云 API，不走 BLE

**smartbike.app 限制**:
- macOS Gatekeeper **rejected**（无签名）
- iOS app wrapper 跑在 Mac 上（Catalyst-ish）
- AppleScript System Events 报 -25211（辅助功能权限未生效）
- AppleScript click 按钮报 -1728（errAEEventNotHandled）
- Quartz `CGEventPost` 看起来成功但实际被 TCC 拦截
- 11 个 deep link 调用，app 完全不响应
- **结论**: iOS-wrapped Mac app + Gatekeeper rejected = GUI 自动化基本无解

**mitmproxy + iPhone HTTPS 抓包成果**:
- 工具: mitmproxy v12.2.3 (via `pipx install mitmproxy`)，端口 8080
- 抓包文件: `~/projects/xdao-ebike-cli/captures/mitm_smartbike.flow` (82.8 MB+)
- Mac IP: **192.168.1.102** / iPhone IP: **192.168.1.26** (同网段)
- **云端域名**: `api.xdaoebike.com`
- **开锁 endpoint**: `POST /smartBike/vehicle/VehicleCommand/V2/sendExec`
- **抓到的 JWT 字段**: jti `03d1ef52e7a242ea8eaa5756dbc6fffe`, rtId `4c3773f224da4781b637624e8f5944ab`
- **鉴权**: Bearer JWT in `authorization` header
- **iPhone app User-Agent**: `libcurl-agent/1.0` (iOS 用了 libcurl)

**重大障碍**: Mac 用 Python 直接重放同样的请求 → `code:2102 身份验证失败`，但 iPhone app 同 token 成功 → **服务端做了 TLS 指纹检测 (JA3/JA4)**，Python urllib 与 iPhone libcurl TLS 握手不同

**mitmproxy 装证书到 iPhone 的标准流程**:
1. iPhone Wi-Fi → Configure Proxy → Manual → 192.168.1.102:8080
2. Safari 访问 `http://mitm.it` (mitmproxy 特殊域名, 返回证书下载页) 或 Plan B: `http://192.168.1.102:8081/mitmproxy-ca.cer` (本地 HTTP 服务器)
3. 设置 → 通用 → VPN 与设备管理 → 安装描述文件
4. **关键一步**: 设置 → 通用 → 关于 → **证书信任设置** → 打开 mitmproxy (很多人漏)
5. 关 iCloud Private Relay（绕过本地代理）

### 工具安装笔记

- **`brew install` 失败**: Homebrew **Tier 3 限制** —— Apple Silicon 上某些包（如 `cliclick`）没有 bottles，`--build-from-source` 会超时失败
- **`vivid-fj` session 卡死**: 编译 cliclick from source 阻塞时 kill 会失败，需手动 SIGTERM
- **mitmproxy**: 装 pipx 而非 pip，CA 默认 `~/.mitmproxy/mitmproxy-ca-cert.pem`
- **bleak**: macOS 原生支持 CoreBluetooth，scan + connect 都免权限（除首次蓝牙权限）
- **PyObjC + Quartz**: 未装；macOS 上合成点击事件即使装了也需要辅助功能权限
- **iCloud Private Relay**: 默认开启会绕过本地代理抓包，必须关
