### 项目要点（已沉淀到 MEMORY.md）

- **核心**：用 OpenStreetMap (OSM) + Overpass API 数据，把世界任何地点一键生成 Minecraft 世界（Java + Bedrock 双版）
- **工作流**：输入坐标/框选区域 → 抓 Overpass API OSM 数据 → 解析建筑/道路/水/公园/高程 → 转 Minecraft 方块（**墙、屋顶、窗户、门都按真实楼层高度复现**）→ 输出完整 world 文件
- **4 年打磨细节度高**——不是「一栋楼一个方块」的简化
- **装法**：`cargo install arnis` / 预编译 binary / Tauri GUI
