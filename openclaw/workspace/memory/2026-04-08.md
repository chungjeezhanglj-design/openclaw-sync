
### 拼音搜索实现
```python
from pypinyin import lazy_pinyin

def generate_pinyin(name):
    initials = ''.join([p[0].upper() for p in lazy_pinyin(name)])
    full_pinyin = ''.join(lazy_pinyin(name))
    return {"pinyin": initials, "pinyin_full": full_pinyin}
```

## 💡 经验教训

### 成功经验
1. 使用 Git LFS 绕过 SSL 证书问题
2. 新浪财经数据源比东方财富更稳定
3. 自建股票池 + 本地搜索响应快

### 踩过的坑
1. `max_length` vs `max_chars` - Streamlit API 细节
2. 中文字符串引号问题 - 必须用英文引号
3. `label_visibility="collapsed"` 导致交互异常
4. session_state 状态传递需要仔细处理
