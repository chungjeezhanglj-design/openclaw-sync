### 项目要点（已沉淀到 MEMORY.md）

- Apple 自家 Virtualization.framework + PCC research VM 基础设施
- 要求 Apple Silicon + macOS 15+ + SIP/AMFI 放权（恢复模式 `csrutil disable` + `amfi_get_out_of_my_way=1`）
- 一条命令：`vphone-cli vm create myphone -V jb` 走完整管线（下 IPSW → patch → DFU restore → CFW 装 → 启动）
- 5 variant：`less`(4 patch, 保 mitigations) / `regular`(42) / `dev`(53) / `jb`(113, Sileo 自启) / `exp`(141, 反 VM 检测)
- 装好 SSH `ssh -p 22222 mobile@<vm-ip>` / VNC `vnc://<vm-ip>:5901`
- 装法：`brew install zqxwce/tap/vphone-cli`
