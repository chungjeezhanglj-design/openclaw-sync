## 15:13 — JackLee 追问"是什么架构"

抓 README 拿到完整技术栈（之前 TL;DR 那一版是推测，现在确认）。

### 确认的技术栈（README 原文）
- **核心**：Tauri 2 + Rust（`cargo tauri dev` 构建）
- **前端**：Vue 3 + Vite + Tailwind CSS + daisyUI（`src-vite/` 目录）
- **数据**：SQLite
- **AI 推理引擎**：ONNX Runtime（Apple Silicon → Core ML EP，Win → DirectML，Linux → CUDA/CPU）
- **AI 模型**：OpenAI CLIP（图文相似/视觉相似/多语言搜索）+ InsightFace（人脸检测/聚类，buffalo_l 模型）
- **图像解码**：LibRaw（RAW）+ libheif（HEIC/HEIF/HIF）+ libjpeg-turbo（JPEG 缩略图）
- **视频**：FFmpeg sidecar（独立二进制，不进 Tauri 包体）+ Video.js 播放 UI
- **地图**：Leaflet
- **构建依赖**：Node.js 20+ + pnpm + Rust stable + 系统库（nasm/autoconf/cmake 等）

### 跟 JackLee 已关注项目的对照
- **MicYou**（2026-08-06）：Tauri 2 + Rust + Vue 3 + Vite + Tailwind —— 音频 DSP 路由
- **Lap**（2026-08-11）：Tauri 2 + Rust + Vue 3 + Vite + Tailwind —— 本地 AI 媒体库
- **Terax AI**（2026-07-31）：Tauri 2 + Rust + React 19 + WebGL 终端

2026 年 Rust 桌面端的"标准答案"是 Tauri 2 + Rust + Vue 3 + Vite + Tailwind；只有 Terax AI 用 React 19（因为它需要 WebGL 终端这个特殊需求）。这个判断值得写一篇对比笔记（JackLee 2026-08-06 已经留过 TODO）。

### AI 架构为什么选 ONNX Runtime + CLIP + InsightFace
- ONNX Runtime 跨平台 EP 自动选最优（Apple Silicon GPU 加速通过 Core ML EP）
- CLIP 多语言版本天然支持 50+ 语言搜索（multilingual CLIP）
- InsightFace 是当前开源人脸识别的 SOTA 之一，buffalo_l 模型精度/速度平衡好
- 三者都是 ONNX 格式 → 同一套推理引擎 → 部署简化

### 商业影响
- **GPL-3.0-or-later**：比 MIT/Apache 严格。如果 JackLee 后续想做衍生商业产品（比如给 NAS 用户做付费版），要谨慎。但个人/学习/内部用没影响。
- 自己编译门槛较高（Node 20+ / pnpm / Rust / Xcode CLT / webkit2gtk 等 + 下载模型 + 下载 FFmpeg sidecar）。普通用户直接装 release .dmg/.msi/.deb 就行。
