### 核心定位
**本地优先 + MCP + AI Agent 的统一 Web 层** —— 替代 Firecrawl / Exa / Tavily 的付费服务。
- 缓存、embeddings、模型、配置全部本地化在 `~/.wigolo/`
- 默认 0 API key、0 云、$0/query
- 可选 LLM provider：anthropic · openai · groq · gemini · **ollama / OpenAI-compatible**（可接华矿机）
- 所有数据"nothing leaves ~/.wigolo/ unless you opt in"

### 10 大工具（README 列的）
1. **search** — 18 个直接适配器，多引擎 rank fusion + ML reranking + 可解释打分；支持并行 query array / 时间范围 / domain scope / 图片
2. **fetch** — 单 URL 抓取，分层路由（HTTP → 无头浏览器），自动升级；返回 clean markdown + metadata + links；支持 PDF / SPA / auth / 点击输入滚动截图
3. **crawl** — 多页爬（BFS / DFS / sitemap / map-only）；每域限速、robots.txt 尊重、boilerplate 去重
4. **extract** — 结构化数据：tables / metadata / JSON-LD / brand identity / 命名 schema (Article/Recipe/Product) / 自定义 JSON Schema
5. **cache** — 关键词 + 混合语义检索；stats / clear / change detection
6. **find_similar** — URL 或 concept 相似页，3 路融合（keyword + semantic + live web）
7. **research** — 分解问题 → 并发子查询 → 抓源 → 综合带引用报告（无 LLM 时给 raw brief 让 host agent 拼）
8. **agent** — 自主 gather loop：plan → search → fetch → extract → synthesize，含 step log + time budget + 可选 output schema
9. **diff** — 对比上次访问差异
10. **watch** — 定期检查 + 变更推送 webhook

### Quickstart
```bash
npx wigolo init                              # 初始化本地引擎（macOS/Linux/Windows）
npx wigolo init --agents=claude-code,cursor  # 一次性接入多个 agent
npx wigolo doctor                            # 健康检查
npx wigolo serve                             # 启 REST 127.0.0.1:3333（off-loopback 需 bearer token）
```
要求 Node ≥ 20 + ~1.5 GB 磁盘（首次 init 下载 browser engine + 本地 models）

### 输出特性
- 每个搜索结果带 verbatim excerpt + byte-pinned source span + citation ID + 可解释 score
- 弱结果被自家 scorer 标 `junk`，明确不藏
- 失败引擎 / 过期缓存 / 被 anti-bot 拦的页面都用明确 label 标出来（不返回伪内容）
