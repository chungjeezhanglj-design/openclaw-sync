## 🎯 新功能

### 🛣️ 真实路径规划

使用 MBTiles 中的 **streets 矢量数据** 进行路径匹配和规划，而不是简单的直线模拟。

| 特性 | 说明 |
|------|------|
| **数据源** | MBTiles 中的 streets 图层（OpenStreetMap 数据） |
| **算法** | Dijkstra 最短路径算法 |
| **路径匹配** | 自动匹配到最近的道路节点 |
| **导航步骤** | 基于真实道路走向生成转向指令 |
| **离线运行** | 完全离线，无需网络连接 |

## 🛣️ 路径规划使用流程

### 1️⃣ 选择起点和终点

- 点击 **"🛣️ 路径规划"** 按钮打开面板
- 点击 **"📍 在地图上选择"** 按钮
- 在地图上点击选择起点
- 同样方式选择终点

### 2️⃣ 选择出行方式

- 🚗 **驾车** - 假设速度 60km/h
- 🚶 **步行** - 假设速度 5km/h
- 🚴 **骑行** - 假设速度 20km/h

### 3️⃣ 开始规划

点击 **"🚗 开始规划"** 按钮

系统会：
1. 查询 MBTiles 中的 streets 数据
2. 构建路网图
3. 使用 Dijkstra 算法计算最短路径
4. 生成导航步骤
5. 将路径渲染到地图上

### 4️⃣ 查看结果

- **路径摘要**：总距离和预计时间
- **导航步骤列表**：详细的转向指示
- **地图渲染**：蓝色路径线沿真实道路显示
- **点击步骤**：地图自动定位到该位置

## 🔧 技术架构

### 路径规划服务 (`route-server.py`)

```
┌─────────────────────────────────────────────────────────┐
│                    用户浏览器                            │
│  ┌─────────────────────────────────────────────────┐   │
│  │  map-ultimate-v2.html                            │   │
│  │  - 路径规划 UI                                    │   │
│  │  - 路径渲染                                       │   │
│  │  - 导航步骤显示                                   │   │
│  └─────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────┘
                            ↓ HTTP 请求
┌─────────────────────────────────────────────────────────┐
│              路径规划服务 (端口 8084)                      │
│  ┌─────────────────────────────────────────────────┐   │
│  │  MBTilesRouter                                   │   │
│  │  - 加载瓦片数据                                   │   │
│  │  - 构建路网图                                     │   │
│  │  - Dijkstra 最短路径                              │   │
│  │  - 生成导航步骤                                   │   │
│  └─────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────┘
                            ↓ 瓦片查询
┌─────────────────────────────────────────────────────────┐
│              MBTiles 服务器 (端口 8083)                    │
│  ┌─────────────────────────────────────────────────┐   │
│  │  china-shortbread-1.0.mbtiles (6.67GB)          │   │
│  │  - streets 图层                                   │   │
│  │  - 道路几何数据                                   │   │
│  │  - 道路属性（名称、等级等）                        │   │
│  └─────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────┘
```

### 路网图构建

```python
class RoadGraph:
    - nodes: 道路节点（坐标点）
    - edges: 道路边（节点间的连接）
    - dijkstra(): 最短路径算法
    - find_nearest_node(): 查找最近的道路节点
```

### PBF 解析

```python
parse_pbf() → 解析矢量瓦片
  ↓
parse_layer() → 解析图层
  ↓
parse_feature() → 解析道路要素
  ↓
decode_geometry() → 解析几何坐标
```

## 📊 性能说明

### 首次规划

- **瓦片加载**：约 1-3 秒（取决于路径长度）
- **路径计算**：约 0.1-0.5 秒
- **总耗时**：约 1-5 秒

### 后续规划

- **瓦片已缓存**：约 0.1-1 秒
- **路径计算**：约 0.1-0.5 秒
- **总耗时**：约 0.2-1.5 秒

### 优化建议

1. **预加载常用区域**：启动时预加载城市中心瓦片
2. **瓦片缓存**：已加载的瓦片会缓存在内存中
3. **Zoom 级别**：使用 zoom 12-13 平衡精度和性能

## 🔍 API 接口

### 路径规划接口

```
GET http://localhost:8084/route?start_lng=116.4&start_lat=39.9&end_lng=116.5&end_lat=39.95&zoom=12
```

**参数**：
- `start_lng` - 起点经度
- `start_lat` - 起点纬度

- `zoom` - 瓦片 zoom 级别（可选，默认 12）

## ⚠️ 注意事项

### 数据限制

1. **MBTiles 数据范围**：仅包含中国境内数据
2. **道路完整性**：取决于 OSM 数据质量
3. **单行道**：当前未处理单行道限制
4. **转向限制**：当前未处理禁止转向限制

### 性能限制

1. **内存占用**：路网图构建需要较多内存（约 500MB-1GB）
2. **首次加载**：首次规划需要加载瓦片，速度较慢
3. **长距离规划**：跨城市路径规划可能较慢

### 精度说明

1. **路径匹配**：自动匹配到最近的道路（误差约 10-50 米）
2. **距离计算**：基于 Haversine 公式（球面距离）
3. **时间估算**：基于固定速度，未考虑交通状况

## 🛠️ 故障排查

### 路径服务无法启动

```bash
# 检查端口是否被占用
lsof -i :8084

# 检查 Python 依赖
python3 --version  # 需要 Python 3.8+
```

### 路径规划失败

1. **检查服务状态**：访问 http://localhost:8084/health
2. **查看日志**：路径规划服务会输出详细日志
3. **检查 MBTiles 文件**：确保文件存在且完整

### 路径不准确

1. **提高 Zoom 级别**：使用 zoom 13-14 获得更详细的路网
2. **检查数据质量**：某些区域的 OSM 数据可能不完整
3. **查看控制台日志**：浏览器控制台会显示路径点数
