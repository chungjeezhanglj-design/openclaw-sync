## 🎯 方案 1：下载完整数据

### 选项 A: Geofabrik 中国提取版（推荐）

Geofabrik 提供基于 OSM 的完整中国道路数据提取。

**下载地址**:
```
https://download.geofabrik.de/asia/china.html
```

**推荐文件**:
- `china-latest-free.shp.zip` - Shapefile 格式（需要转换）
- 或使用 BBBike 提取特定城市

### 选项 B: BBBike 自定义提取（最灵活）

BBBike 提供按需提取服务，可以选择特定区域和道路类型。

**步骤**:
1. 访问 https://extract.bbbike.org/
2. 选择区域（如石家庄市）
3. 选择格式：**MBTiles** 或 **PBF**
4. 选择道路类型：勾选所有道路等级
5. 填写邮箱，等待下载链接

### 选项 C: 使用 Shortbread 完整规范

Shortbread 规范包含完整的道路等级。

**下载**:
```
https://github.com/shortbread/maps
```

## 🔧 方案 2：从 PBF 转换（技术向）

如果已有 OSM PBF 文件，可以转换为 MBTiles。

### 步骤 1: 下载中国 PBF 数据
```bash
# Geofabrik 中国 PBF
wget https://download.geofabrik.de/asia/china-latest.osm.pbf
```

### 步骤 2: 使用 TileMill 或 Tippecanoe 转换
```bash
# 使用 tilemaker
tilemaker --input china-latest.osm.pbf \
          --output china-complete.mbtiles \
          --config tilemaker/resources/config.json \
          --process tilemaker/resources/process.lua
```

### 步骤 3: 验证数据
```bash
# 检查包含的道路类型
sqlite3 china-complete.mbtiles "SELECT DISTINCT kind FROM tiles WHERE zoom_level=12 LIMIT 20"
```
