## 2. 推荐数据源

### 2.1 Natural Earth (推荐 ⭐⭐⭐⭐⭐)

**网址**: https://www.naturalearthdata.com/

**优点**:
- ✅ 免费开源，无需注册
- ✅ 全球覆盖，包含中国
- ✅ 多级行政边界 (Admin 0-2)
- ✅ 多种格式 (Shapefile, GeoJSON, SQLite)
- ✅ 1:10m 精度适合中小比例尺地图

**数据分类**:
| 数据集 | 说明 | 对应 admin_level |
|--------|------|-----------------|
| **Admin 0 - Countries** | 国界 | 2 |
| **Admin 0 - Boundary Lines** | 国界线 | 2 |
| **Admin 1 - States, Provinces** | 省界 | 4 |
| **Admin 2 - Counties** | 县界 | 6 |

**下载链接**:
- 国界：https://www.naturalearthdata.com/downloads/10m-cultural-vectors/10m-admin-0-countries/
- 省界：https://www.naturalearthdata.com/downloads/10m-cultural-vectors/10m-admin-1-states-provinces/
- 县界：https://www.naturalearthdata.com/downloads/10m-cultural-vectors/10m-admin-2-counties/

**格式**: Shapefile (含 .shp, .shx, .dbf, .prj)

## 3. 数据处理流程

### 方案 A: Natural Earth + MBTiles

```bash
# 1. 下载 Natural Earth 数据
wget https://naciscdn.org/naturalearth/10m/cultural/ne_10m_admin_0_countries.zip
wget https://naciscdn.org/naturalearth/10m/cultural/ne_10m_admin_1_states_provinces.zip

# 2. 解压
unzip ne_10m_admin_0_countries.zip
unzip ne_10m_admin_1_states_provinces.zip

# 3. 转换为 GeoJSON (使用 ogr2ogr)
ogr2ogr -f GeoJSON countries.geojson ne_10m_admin_0_countries.shp
ogr2ogr -f GeoJSON provinces.geojson ne_10m_admin_1_states_provinces.shp

# 4. 合并到现有 MBTiles (使用 tippecanoe 或 mb-util)
# 或者创建新的边界专用 MBTiles
```

### 方案 B: OSM 数据提取

```bash
# 1. 下载中国 OSM 数据
wget http://download.geofabrik.de/asia/china-latest.osm.pbf

# 2. 使用 osmium 提取边界
osmium tags-filter china-latest.osm.pbf r/admin_level=2 r/admin_level=4 r/admin_level=6 -o china-boundaries.osm.pbf

# 3. 转换为 MBTiles (使用 imposm 或 custom script)
```

### 方案 C: 阿里云 DataV (最简单)

```bash
# 1. 直接下载 GeoJSON
curl -o china-provinces.geojson https://geo.datav.aliyun.com/areas_v3/bound/100000_full.json

# 2. 添加到地图中作为独立图层
# 在 MapLibre 中作为 GeoJSON 源添加
```

## 5. 实施步骤

### 第一步：下载阿里云边界数据

```bash
cd /Users/zhanglj/openclaw/workspace/离线地图项目/data/

# 下载中国省级边界
curl -o china-provinces.geojson \

curl -o ne_countries.zip \
  "https://naciscdn.org/naturalearth/10m/cultural/ne_10m_admin_0_countries.zip"
unzip ne_countries.zip
```

### 第二步：转换为 MBTiles

```bash
# 使用 tippecanoe 创建边界专用 MBTiles
tippecanoe -o boundaries.mbtiles \
  --minimum-zoom=0 \
  --maximum-zoom=14 \
  --layer=boundaries \
  china-provinces.geojson
```

### 第三步：在地图中添加边界图层

```javascript
// 在 style.json 中添加
{
  "id": "province-boundaries",
  "type": "line",
  "source": "boundaries",
  "source-layer": "boundaries",
  "minzoom": 5,
  "paint": {
    "line-color": "#e67e22",
    "line-width": 2,
    "line-dasharray": [4, 2]
  }
}
```
