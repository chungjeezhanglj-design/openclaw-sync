## 1. 项目概述

### 1.1 项目背景
构建一套完全离线的中国地图系统，支持在无需网络连接的环境下查看、浏览、分析中国地理信息数据。适用于内网部署、野外作业、安全敏感场景等。

### 1.2 项目目标
- ✅ 完全离线运行，无需任何外部网络依赖
- ✅ 支持全国范围地图浏览（zoom 0-14）
- ✅ 支持多层级地理要素显示（水系、道路、居民地、兴趣点等）
- ✅ 支持图层自由开关控制
- ✅ 支持道路分级显示（高速公路、国道、省道等）
- ✅ 轻量级部署，单文件数据源

## 3. 系统架构

### 3.1 技术栈
| 组件 | 技术选型 | 说明 |
|------|----------|------|
| 地图渲染引擎 | MapLibre GL JS v4.7.1 | 开源 WebGL 地图库 |
| 瓦片服务 | Python 3 + SQLite | 轻量级 MBTiles 服务器 |
| HTTP 服务 | Python http.server | 静态文件服务 |
| 数据格式 | MBTiles/PBF | 标准矢量瓦片格式 |
| 前端框架 | 原生 HTML/JS | 零依赖，单文件 |

### 3.2 系统架构图
```
┌─────────────────────────────────────────────────────────┐
│                      用户浏览器                          │
│  ┌─────────────────────────────────────────────────┐   │
│  │           MapLibre GL JS (WebGL 渲染)            │   │
│  │  ┌─────────────────────────────────────────┐   │   │
│  │  │         地图样式配置 (Style JSON)        │   │   │
│  │  │  - 26 个图层定义                          │   │   │
│  │  │  - 道路分级样式                          │   │   │
│  │  │  - 图层可见性控制                        │   │   │
│  │  └─────────────────────────────────────────┘   │   │
│  └─────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────┘
                            ↓ HTTP 请求
┌─────────────────────────────────────────────────────────┐
│                   HTTP 服务器 (端口 8082)                 │
│  - 提供 HTML/CSS/JS 静态文件                              │
│  - 提供地图查看器页面                                    │
└─────────────────────────────────────────────────────────┘
                            ↓ 瓦片请求
┌─────────────────────────────────────────────────────────┐
│              MBTiles 服务器 (端口 8083)                   │
│  ┌─────────────────────────────────────────────────┐   │
│  │  Python HTTP Server + SQLite                    │   │
│  │  - 接收瓦片请求 /{z}/{x}/{y}.pbf                 │   │
│  │  - 坐标转换 (XYZ → TMS)                          │   │
│  │  - 从 MBTiles 读取瓦片数据                         │   │
│  │  - 返回 gzip 压缩的 PBF 数据                        │   │
│  └─────────────────────────────────────────────────┘   │
│  ┌─────────────────────────────────────────────────┐   │
│  │        china-shortbread-1.0.mbtiles (6.67GB)    │   │
│  │        SQLite 数据库，存储所有瓦片                  │   │
│  └─────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────┘
```

## 6. 性能需求

### 6.1 响应时间
- 首屏加载：< 3 秒
- 瓦片加载：< 500ms/瓦片
- 页面切换：< 1 秒

### 6.2 资源占用
- 内存占用：< 500MB (浏览器)
- CPU 占用：< 30% (常规浏览)
- 磁盘空间：7GB (含数据文件)

### 6.3 并发支持
- 单用户模式（本地部署）
- 不支持高并发（非设计目标）

## 7. 部署需求

### 7.1 运行环境
| 组件 | 要求 |
|------|------|
| 操作系统 | Windows / macOS / Linux |
| Python | 3.8+ |
| 浏览器 | Chrome 90+ / Firefox 88+ / Edge 90+ |
| 内存 | 8GB+ (推荐 16GB) |
| 磁盘 | 10GB 可用空间 |

### 7.2 启动流程
```bash
# 1. 启动 MBTiles 服务器
python3 mbtiles-server.py china-shortbread-1.0.mbtiles 8083 &

# 2. 启动 HTTP 服务器
python3 -m http.server 8082 &

# 3. 打开浏览器
open http://localhost:8082/
```
