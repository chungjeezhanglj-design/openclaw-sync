### 3️⃣ 测量工具

#### 📏 距离测量

**功能**: 测量两点或多点之间的距离

**使用方法**:
1. 点击 "📏 距离测量" 按钮
2. 在地图上点击添加测量点
3. 双击结束测量
4. 结果显示在工具箱中（米/公里）

**精度**:
- 使用 Haversine 公式计算球面距离
- 考虑地球曲率，适合长距离测量
- 误差 < 0.5%

#### 📐 面积测量

**功能**: 测量多边形区域的面积

**使用方法**:
1. 点击 "📐 面积测量" 按钮
2. 在地图上点击添加顶点
3. 双击闭合多边形并结束
4. 结果显示在工具箱中（公顷/平方公里）

**精度**:
- 使用球面多边形面积公式
- 自动闭合多边形
- 适合大范围区域测量

**测量结果显示**:
- 距离 < 1000 米 → 显示 "XXX 米"
- 距离 ≥ 1000 米 → 显示 "X.XX 公里"
- 面积 < 100 公顷 → 显示 "X.XX 公顷"
- 面积 ≥ 100 公顷 → 显示 "X.XX 平方公里"

## ⚠️ 注意事项

### 市界数据
- 当前默认加载广州市界
- 修改市界需编辑 HTML 中的 `city-boundary` 源
- 可添加多个城市，通过图层控制切换

### 道路样式
- 分级道路样式需要 zoom 10+ 才能看到效果
- zoom 14+ 才能看到完整的道路分级
- 切换样式会短暂闪烁（正常现象）

### 测量工具
- 测量结果仅供参考，不用于精确测量
- 长距离测量考虑地球曲率
- 面积测量需要闭合多边形
