## 1. 项目概述

### 1.1 项目背景
构建一套完全离线的中国地图系统，支持在无需网络连接的环境下查看、浏览、分析中国地理信息数据。适用于内网部署、野外作业、安全敏感场景等。

### 1.2 项目目标

| 目标 | 状态 | 说明 |
|------|------|------|
| 完全离线运行 | ✅ 完成 | 仅需 MBTiles 数据文件 + Python 服务器 |
| 全国范围地图浏览 | ✅ 完成 | Zoom 0-14 级完整支持 |
| 多层级地理要素显示 | ✅ 完成 | 26 个图层完整支持 |
| 图层自由开关控制 | ✅ 完成 | 20 个可控制图层，8 个分类 |
| 道路分级显示 | ✅ 完成 | 7 级道路分级样式 |
| 行政边界显示 | ✅ 完成 | 国界 + 省界 + 市界（阿里云 DataV） |
| 测量工具 | ✅ 完成 | 距离测量 + 面积测量 |
| 轻量级部署 | ✅ 完成 | 单 HTML 文件 + 数据文件 |

## 3. 系统架构

### 3.1 技术栈

| 组件 | 技术选型 | 说明 |
|------|----------|------|
| 地图渲染引擎 | MapLibre GL JS v4.7.1 | 开源 WebGL 地图库 |
| 瓦片服务 | Python 3 + SQLite | 轻量级 MBTiles 服务器 |
| HTTP 服务 | Python http.server | 静态文件服务 |
| 数据格式 | MBTiles/PBF/GeoJSON | 矢量瓦片 + 边界数据 |

## 11. 技术说明

### 11.1 MBTiles 服务器

**文件**: `mbtiles-server.py`

**功能**:
- 读取 MBTiles 数据库
- XYZ → TMS 坐标转换
- 返回 gzip 压缩的 PBF 瓦片
- 设置正确的 Content-Type 和 Content-Encoding

**端口**: 8083

### 11.2 地图渲染

**引擎**: MapLibre GL JS v4.7.1

**特点**:
- WebGL 硬件加速
- 矢量瓦片实时渲染
- 支持 3D 变换（未启用）
- 支持自定义样式

### 11.3 边界数据

**来源**: 阿里云 DataV

**格式**: GeoJSON

**处理**:
- 直接通过 HTTP 加载
- 作为 GeoJSON 源添加到地图
- 独立图层控制

## 12. 常见问题

### Q1: 地图加载慢？
**A**: MBTiles 数据较大 (6.67GB)，首次加载需要时间。建议：
- 使用 SSD 存储
- 增加 MBTiles 服务器缓存
- 预加载常用区域瓦片

### Q2: 边界数据显示不正确？
**A**: 检查 GeoJSON 文件路径是否正确，确保 HTTP 服务器已启动。

### Q3: 测量工具不准确？
**A**: 测量结果基于球面公式计算，适合大范围测量。小范围测量可能存在误差。

### Q4: 道路分级不明显？
**A**: 需要 zoom 10+ 才能看到效果，zoom 14+ 效果最佳。
