# 📁 CAD 文件上传功能使用说明

**版本**: v1.0  
**更新日期**: 2026-03-16

---

## 🎯 功能概述

支持上传 **SVG** 和 **DXF** 格式的 CAD 文件，自动转换为地理坐标并在地图上显示。

**适用场景**:
- 🏗️ 建筑规划图叠加
- 🗺️ 地块边界导入
- 📐 工程图纸定位
- 🏘️ 小区平面图展示

---

## 📤 上传文件

### 1. 访问上传页面

**地址**: http://localhost:8082/离线地图项目/upload-cad.html

或者从主页面点击工具箱中的 **"📁 上传 SVG/DXF"** 按钮。

### 2. 选择文件

支持两种方式：
- **拖拽上传**: 直接将文件拖到上传区域
- **点击上传**: 点击上传区域选择文件

**支持格式**:
- ✅ `.svg` - Scalable Vector Graphics
- ✅ `.dxf` - AutoCAD Drawing Exchange Format

**文件大小**: 建议 < 10MB

### 3. 解析文件

上传后系统会自动解析文件中的几何图形：

**SVG 支持**:
- ✅ `<path>` - 路径
- ✅ `<line>` - 线段
- ✅ `<circle>` - 圆形
- ✅ `<rect>` - 矩形
- ✅ `<polygon>` - 多边形

**DXF 支持**:
- ✅ `LINE` - 线段
- ✅ `POLYLINE` - 多段线
- ✅ `LWPOLYLINE` - 轻量多段线
- ✅ `CIRCLE` - 圆
- ✅ `ARC` - 圆弧
- ✅ `POINT` - 点

## ⚙️ 参数设置

### 坐标转换参数

| 参数 | 说明 | 默认值 |
|------|------|--------|
| **中心经度** | 地图中心点经度 | 114.50 |
| **中心纬度** | 地图中心点纬度 | 38.04 |
| **缩放比例** | CAD 坐标到地理坐标的缩放 | 0.0001 |
| **旋转角度** | 逆时针旋转角度（度） | 0 |
| **翻转 Y 轴** | CAD 坐标系 Y 轴向上，地理坐标系向下 | ✅ 勾选 |

### 样式设置

| 参数 | 说明 | 默认值 |
|------|------|--------|
| **线条颜色** | 边界线颜色 | #9b59b6 (紫色) |
| **线条宽度** | 边界线宽度（像素） | 2 |
| **填充颜色** | 多边形填充颜色 | #9b59b6 |
| **透明度** | 0-1，0 完全透明，1 不透明 | 0.8 |

### 🎯 自动适配

点击 **"自动适配"** 按钮，系统会自动计算：
- 几何中心点作为地图中心
- 根据图形大小计算合适的缩放比例

## 🗺️ 在地图上显示

### 方法 1: 从上传页面

1. 设置好参数后点击 **"🗺️ 在地图上显示"**
2. 系统会自动打开新窗口显示地图

### 方法 2: 直接访问地图页面

**地址**: http://localhost:8082/离线地图项目/map-cad-upload.html

地图会自动加载上次上传的数据和设置。

### 地图操作

| 操作 | 说明 |
|------|------|
| **拖拽** | 移动地图 |
| **滚轮** | 缩放地图 |
| **右键旋转** | 旋转地图方向 |
| **图层开关** | 右侧面板控制线条/填充显示 |
| **清除所有** | 删除上传的数据 |

## 📝 使用示例

### 示例 1: 上传建筑平面图

1. 准备 SVG 格式的建筑平面图
2. 访问上传页面，拖拽文件到上传区域
3. 点击 **"自动适配"** 计算参数
4. 调整线条颜色为红色 (#ff0000)
5. 点击 **"在地图上显示"**

### 示例 2: 导入 DXF 地块边界

1. 准备 DXF 格式的地块边界文件
2. 设置中心点为地块实际位置（例如：114.50, 38.04）
3. 调整缩放比例直到大小合适
4. 设置透明度为 0.5 以便看到底图
5. 点击 **"应用设置"** 然后 **"在地图上显示"**

### 示例 3: 叠加多个 CAD 文件

1. 上传第一个文件，设置参数
2. 再次上传第二个文件
3. 两个文件会自动合并
4. 统一调整样式后显示在地图上

## 🔧 高级技巧

### 1. 精确坐标定位

如果知道 CAD 文件的实际地理坐标：

```javascript
// 在浏览器控制台执行
const settings = {
    centerX: 114.50,  // 实际经度
    centerY: 38.04,   // 实际纬度
    scale: 0.0001,    // 根据 CAD 单位调整
    rotation: 0,
    flipY: true
};
localStorage.setItem('cadUploadSettings', JSON.stringify(settings));
```

### 2. 批量上传

可以一次选择多个文件上传，系统会自动合并。

### 3. 保存配置

设置会自动保存到浏览器 localStorage，下次打开页面会自动加载。

### 4. 导出配置

```javascript
// 导出当前配置
const config = {
    settings: localStorage.getItem('cadUploadSettings'),
    style: localStorage.getItem('cadUploadStyle'),
    data: localStorage.getItem('cadUploadGeoJSON')
};
console.log(JSON.stringify(config, null, 2));
```

## ❓ 常见问题

### Q1: 上传后看不到图形？

**A**: 可能是坐标转换参数不正确。尝试：
1. 点击 **"自动适配"** 重新计算
2. 调整 **缩放比例**（增大或减小）
3. 检查 **中心点坐标** 是否正确

### Q2: 图形显示太小/太大？

**A**: 调整 **缩放比例** 参数：
- 图形太小 → 增大缩放比例（例如：0.0001 → 0.001）
- 图形太大 → 减小缩放比例（例如：0.0001 → 0.00001）

### Q3: 图形方向不对？

**A**: 调整 **旋转角度** 参数，输入角度值（0-360）。

### Q4: 支持 3D 模型吗？

**A**: 目前仅支持 2D 矢量图形，不支持 3D 模型。

### Q5: 文件太大怎么办？

**A**: 建议：
- 简化 CAD 图形，删除不必要的细节
- 分割为大文件为多个小文件
- 使用在线工具压缩 SVG

### Q6: 如何在地图上永久保存？

**A**: 目前数据保存在浏览器 localStorage，清除浏览器数据会丢失。如需永久保存：
1. 导出 GeoJSON 数据
2. 保存到本地文件
3. 下次使用时重新上传

## 📊 技术说明

### 坐标系统

**CAD 坐标系**:
- 原点：通常在左下角或中心
- X 轴：向右为正
- Y 轴：向上为正
- 单位：毫米或米

**地理坐标系**:
- 原点：本初子午线和赤道交点
- X 轴：经度，向东为正
- Y 轴：纬度，向北为正
- 单位：度

**转换公式**:
```
地理经度 = CAD_X × scale + centerX
地理纬度 = CAD_Y × scale × (flipY ? -1 : 1) + centerY
```

### 支持的文件大小

| 文件类型 | 最大推荐大小 | 解析时间 |
|---------|-------------|---------|
| SVG | < 5MB | < 1 秒 |
| DXF | < 10MB | < 3 秒 |

### 性能优化

- 超过 1000 个要素时，建议使用简化图形
- 复杂图形可以分层上传
- 使用浏览器开发者工具查看性能
