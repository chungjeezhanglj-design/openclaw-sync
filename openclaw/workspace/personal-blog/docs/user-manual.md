## 1. 快速入门

### 1.1 访问系统

- **本地访问**: http://localhost
- **生产环境**: https://chungjee.cc.cd

### 1.2 注册账号

1. 点击首页右上角 **登录/注册** 按钮
2. 选择 **注册** 标签
3. 填写以下信息：
   - 邮箱地址
   - 密码（至少 6 位）
   - 昵称（2-50 字符）
4. 点击 **注册** 按钮

> 💡 提示：注册成功后会自动登录，Token 有效期为 7 天

### 1.3 登录系统

**方式一：邮箱登录**
1. 输入邮箱和密码
2. 点击 **登录**

**方式二：微信扫码**（如已配置）
1. 点击 **微信登录**
2. 使用微信扫描二维码
3. 授权后自动登录

### 1.4 首次使用

登录后建议完成以下设置：
1. 上传头像
2. 填写个人简介
3. 配置显示偏好
4. （可选）配置 AI 服务

## 2. 用户指南

### 2.1 首页浏览

首页支持 4 种展示布局，点击右上角布局切换按钮：

| 布局 | 说明 | 适用场景 |
|------|------|----------|
| 📍 **时间线** | 左右交替时间轴，带年份标签 | 按时间顺序浏览 |
| 📐 **网格** | 整齐的网格排列 | 快速浏览大量内容 |
| 🌊 **瀑布流** | 不等高卡片错落排列 | 照片为主的内容 |
| 🗺️ **地图** | 地图标记照片位置 | 查看地理分布 |

### 2.2 搜索功能

#### 智能语义搜索

系统支持自然语言搜索，AI 会自动解析你的意图：

**示例：**
- `海边的日落` → 搜索包含"海边的日落"的照片
- `西藏的蓝天` → 搜索地点为"西藏"且包含"蓝天"的照片
- `近三年青岛的海滩` → 搜索 2023 年至今在青岛拍摄的海滩照片
- `去年北京` → 搜索去年在北京拍摄的照片
- `五一期间的厦门` → 搜索五一期间在厦门的照片

**使用步骤：**
1. 点击首页搜索框
2. 输入自然语言描述
3. 点击搜索或按回车
4. AI 解析后显示意图（时间/地点/关键词）
5. 可手动调整解析结果
6. 点击 **确认搜索** 执行

### 2.3 文章详情

点击任意文章卡片进入详情页，可查看：
- 完整文章内容
- 所有照片及 EXIF 信息
- 照片拍摄地点（地图）
- 评论列表
- 点赞和分享功能

## 3. 内容创作

### 3.1 发布文章

#### 步骤一：创建文章
1. 点击顶部导航栏 **写作** 按钮
2. 输入文章标题（必填）
3. 编写文章内容（可选）

#### 步骤二：选择布局
从 4 种布局中选择：
- **时间线**：适合按时间顺序记录
- **网格**：适合多图展示
- **瀑布流**：适合摄影作品
- **地图**：适合旅行记录

#### 步骤三：设置可见性
- **公开**：所有人可见
- **好友**：仅互相关注的好友可见
- **粉丝**：仅关注你的人可见
- **私密**：仅自己可见

#### 步骤四：添加照片
有两种方式：

**方式 A：上传新照片**
1. 点击 **上传照片** 按钮
2. 选择一张或多张照片
3. 等待上传完成
4. （可选）为照片添加描述

**方式 B：选择已有照片**
1. 点击 **从相册选择**
2. 浏览已上传的照片
3. 选择需要的照片

#### 步骤五：添加标签
1. 点击 **添加标签**
2. 选择已有标签或创建新标签
3. 标签有助于分类和搜索

#### 步骤六：发布
- **保存草稿**：暂不发布，后续可编辑
- **立即发布**：公开发布文章

### 3.2 编辑文章

1. 进入文章详情页
2. 点击右上角 **编辑** 按钮（仅作者或编辑可见）
3. 修改内容后点击 **保存**

### 3.3 删除文章

1. 进入文章详情页
2. 点击右上角 **更多** → **删除**
3. 确认删除

> ⚠️ 警告：删除后无法恢复，关联的照片会保留在相册中

### 3.4 照片管理

#### 上传照片
1. 点击顶部导航栏 **上传** 按钮
2. 选择照片文件（支持多选）
3. 等待上传完成

#### 查看相册
1. 进入 **个人主页**
2. 点击 **相册** 标签
3. 浏览所有已上传照片

#### AI 分析照片
1. 在相册中找到照片
2. 点击 **AI 分析** 按钮
3. 等待 AI 分析完成
4. 查看 AI 生成的标题和标签

> 💡 提示：AI 分析需要配置 AI 服务，见 [6.4 AI 配置](#64-ai-配置)

#### 编辑照片信息
- **描述**：添加或修改照片描述
- **标签**：添加或修改照片标签
- **位置**：手动设置拍摄地点（如自动识别失败）

## 4. 智能功能

### 4.1 AI 照片分析

系统支持多种 AI 服务提供商分析照片内容：

**支持的服务商：**
| 服务商 | 类型 | 说明 |
|--------|------|------|
| Ollama | 本地 | 需自行部署，免费 |
| 通义千问 | 云端 | 阿里云，需 API Key |
| MiniMax | 云端 | 海螺 AI，需 API Key |
| 月之暗面 | 云端 | Kimi，需 API Key |

**分析内容：**
- 自动生成照片标题
- 自动提取关键词标签
- 置信度评分

### 4.2 语音朗读

系统支持将文章内容转换为语音朗读：

**使用方法：**
1. 打开任意文章
2. 点击文章底部的 **🔊 朗读** 按钮
3. 开始播放
4. 再次点击可暂停/停止

> 💡 提示：使用 macOS 本地 TTS，无需额外 API

### 4.3 地图模式

地图模式展示所有带 GPS 坐标的照片：

**使用方法：**
1. 在首页切换为 **地图** 布局
2. 查看照片在地图上的分布
3. 点击标记查看照片详情

**GPS 来源：**
- 照片 EXIF 自动提取
- 手动设置位置

## 5. 社交互动

### 5.1 关注用户

**关注：**
1. 进入用户主页
2. 点击 **关注** 按钮
3. 成为该用户的粉丝

**取消关注：**
1. 进入用户主页
2. 点击 **已关注** 按钮
3. 确认取消

### 5.2 好友关系

- **好友**：互相关注自动成为好友
- **查看好友**：个人主页 → 好友 标签
- **好友文章**：可见性设置为"好友"的文章仅好友可见

### 5.3 点赞文章

1. 在文章卡片或详情页点击 ❤️ 图标
2. 再次点击取消点赞
3. 在个人主页可查看 **我点赞的文章**

### 5.4 发表评论

1. 进入文章详情页
2. 滚动到底部评论区域
3. 输入评论内容
4. 点击 **发表**

**回复评论：**
1. 点击评论下方的 **回复** 按钮
2. 输入回复内容
3. 点击发送

### 5.5 评论管理

**作者权限：**
- 置顶评论：点击评论的 📌 图标
- 删除评论：点击评论的 🗑️ 图标

**管理员权限：**
- 审核评论：批准或拒绝待审核评论
- 批量操作：一键取消所有评论审批

## 6. 个人设置

### 6.1 个人资料

进入 **个人主页** → **编辑资料**：

**可修改项：**
- 头像：上传新头像
- 昵称：2-50 字符
- 简介：个人介绍
- 手机：联系方式
- 位置：所在城市
- 网站：个人网站或博客
- 性别：男/女/其他
- 生日：出生日期

### 6.2 显示偏好

进入 **个人设置** → **显示偏好**：

**时间显示：**
- **拍摄时间**：优先显示照片拍摄时间
- **创建时间**：显示文章创建时间

**排序偏好：**
- **降序**：最新的在前
- **升序**：最早的在前

### 6.3 账号安全

进入 **个人设置** → **修改密码**：

1. 输入当前密码
2. 输入新密码（至少 8 位）
3. 确认新密码
4. 点击 **修改**

### 6.4 AI 配置

进入 **个人设置** → **AI 配置**：

#### 选择 AI 提供商

**Ollama（推荐）：**
1. 选择 **Ollama**
2. 输入 Ollama 服务地址（如：http://192.168.1.111:11434）
3. 输入模型名称（如：openbmb/minicpm-v4.5:8b）
4. 点击 **测试连接**
5. 点击 **保存**

**云端服务：**
1. 选择对应服务商
2. 输入 API Key
3. 选择模型
4. 点击保存

#### 提示词预设

系统支持自定义 AI 分析提示词：

**创建预设：**
1. 进入 **AI 提示词** 页面
2. 点击 **新建预设**
3. 填写：
   - 名称：如"详细分析"
   - 类型：search（搜索）或 analysis（分析）
   - 描述：预设说明
   - 提示词：AI 指令模板
4. 点击保存

**使用预设：**
1. 在 AI 配置中选择预设
2. 或设为默认预设

**示例提示词（搜索意图解析）：**
```
你是"时间"、"地点"、"关键词"拆分专家，当前 2026-03-03。
地点指地图上的地点，如北京、上海、青岛等。关键词不要去分词。

示例：
海边的日落 → {"startDate":null,"endDate":null,"location":null,"keywords":["海边的日落"]}
西藏的蓝天 → {"startDate":null,"endDate":null,"location":"西藏","keywords":["蓝天"]}
近三年青岛海滩 → {"startDate":"2023-03-03","endDate":"2026-03-03","location":"青岛","keywords":["海滩"]}

请你深度思考解析，语句中不一定有全部的信息，只返回一个 JSON。
```

## 7. 常见问题

### 7.1 账号相关

**Q: 忘记密码怎么办？**
A: 目前系统不支持自助重置密码，请联系管理员重置。

**Q: 如何注销账号？**
A: 请联系管理员删除账号。

**Q: 支持多账号登录吗？**
A: 同一浏览器只能登录一个账号。如需切换，请先退出登录。

### 7.2 内容相关

**Q: 删除的文章能恢复吗？**
A: 不能。删除前请谨慎确认。

**Q: 照片有大小限制吗？**
A: 建议单张照片不超过 10MB，过大的照片会自动压缩。

**Q: 支持哪些图片格式？**
A: 支持 JPG、PNG、GIF、WebP 等常见格式。

**Q: 如何批量上传照片？**
A: 上传时可选择多张照片，建议一次不超过 20 张。

### 7.3 AI 功能

**Q: AI 分析失败怎么办？**
A: 检查以下项：
- AI 服务是否已配置
- 服务地址是否正确
- 网络连接是否正常
- 尝试更换 AI 提供商

**Q: Ollama 如何部署？**
A: 参考 Ollama 官方文档：https://ollama.ai/

**Q: AI 分析收费吗？**
A: 
- Ollama（本地）：免费
- 云端服务：按服务商计费

### 7.4 搜索功能

**Q: 搜索不到结果怎么办？**
A: 
- 检查关键词是否正确
- 尝试更宽泛的搜索词
- 检查时间范围是否合理
- 确认照片是否已发布

**Q: 如何搜索特定地点的照片？**
A: 直接输入地点名称，如"青岛"、"北京故宫"

**Q: 如何搜索特定时间的照片？**
A: 使用自然语言描述，如"去年夏天"、"近三年"、"2025 年"

### 7.5 地图功能

**Q: 地图不显示照片？**
A: 照片需要包含 GPS 坐标才会显示在地图上。检查照片 EXIF 是否包含 GPS 信息。

**Q: GPS 位置不准确？**
A: 可在照片编辑中手动修正位置。

### 7.6 技术支持

**Q: 如何获取帮助？**
A: 
- 查看系统内置帮助页面：/help
- 查看 API 文档：/api-docs
- 联系管理员

**Q: 发现 Bug 如何反馈？**
A: 请通过以下方式反馈：
- 系统内反馈功能
- 联系管理员
- 提交 Issue（如有代码仓库）
