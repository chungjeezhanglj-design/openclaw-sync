## 1. 项目概述

### 1.1 项目背景

博客小时光系统是一款以**照片为核心**的个人博客平台，强调时间与空间维度的内容展示。系统支持用户通过照片记录生活瞬间，并借助 AI 技术实现智能分析、语义搜索和语音朗读等功能。

### 1.2 产品定位

- **目标用户**：摄影爱好者、生活记录者、旅行博主
- **核心价值**：用照片讲述故事，用 AI 赋能创作
- **差异化特色**：
  - GPS 时光地图：照片自动关联拍摄地点
  - AI 智能分析：多模态模型理解照片内容
  - 语义搜索：自然语言解析时间/地点/关键词
  - 语音朗读：本地 TTS 让文章可听化

### 1.3 术语定义

| 术语 | 定义 |
|------|------|
| EXIF | 照片可交换图像文件格式，包含拍摄参数和 GPS 信息 |
| TTS | Text-to-Speech，文本转语音技术 |
| 多模态 AI | 能同时理解图像和文本的人工智能模型 |
| 布局类型 | 文章展示方式：时间线/网格/瀑布流/地图 |

## 8. 部署方案

### 8.1 Docker Compose 部署

```yaml
version: '3.8'

services:
  mariadb:
    image: mariadb:10-alpine
    container_name: blog-mariadb
    environment:
      MARIADB_ROOT_PASSWORD: ${DB_PASSWORD}
      MARIADB_DATABASE: ${DB_DATABASE}
    ports:
      - "3306:3306"
    volumes:
      - mariadb_data:/var/lib/mysql
    networks:
      - blog-network

  backend:
    build: ./backend
    container_name: blog-backend
    environment:
      - NODE_ENV=production
      - PORT=3000
      - DB_HOST=mariadb
      - DB_PORT=3306
      - DB_USERNAME=${DB_USERNAME}
      - DB_PASSWORD=${DB_PASSWORD}
      - DB_DATABASE=${DB_DATABASE}
      - JWT_SECRET=${JWT_SECRET}
    ports:
      - "3000:3000"
    volumes:
      - ./uploads:/app/uploads
    depends_on:
      - mariadb
    networks:
      - blog-network

  frontend:
    build: ./frontend
    container_name: blog-frontend
    ports:
      - "80:80"
    depends_on:
      - backend
    networks:
      - blog-network

volumes:
  mariadb_data:

networks:
  blog-network:
    driver: bridge
```

### 8.3 部署流程

1. **环境准备**
   - 安装 Docker 和 Docker Compose
   - 准备服务器（推荐 2 核 4G 以上）
   - 配置域名和 SSL 证书（可选）

2. **代码部署**
   ```bash
   # 克隆代码
   git clone <repo-url>
   cd personal-blog

   # 配置环境变量
   cp .env.example .env
   vim .env  # 编辑配置

   # 启动服务
   docker-compose up -d
   ```

3. **初始化配置**
   - 访问 `http://localhost/setup`
   - 配置数据库连接
   - 设置管理员账号
   - 完成初始化

4. **后续维护**
   ```bash
   # 查看日志
   docker-compose logs -f backend

   # 重启服务
   docker-compose restart

   # 更新代码
   git pull
   docker-compose up -d --build
   ```
